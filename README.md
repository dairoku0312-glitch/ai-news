# AIニュース自動配信

毎朝8時（日本時間）に公開ニュースを自動収集・要約し、静的サイトに掲載する仕組みです。

## 仕組み

- **収集**: GitHub Actions が毎朝、ニュース各社の公式 RSS（Yahoo!ニュース／NHK／ITmedia）
  から新着記事を取得し、タイトルのキーワードで6カテゴリ
  （介護・福祉／外国人材・特定技能・在留資格／AI・IT／経済・ビジネス／国内政治／海外ニュース）
  に分類します（`scripts/fetch_news.py`、Python標準ライブラリのみ）。
  ※ Google News RSS は記事リンクから元記事の本文をサーバー側で取得できないため使っていません。
- **要約**: 記事本文を取得できたものだけを Gemini API（無料枠）で要約し、
  `data/news.json` に保存します。サイト（GitHub Pages）はこの JSON を表示するだけです。
- **公開**: GitHub Pages で静的サイトとして公開。スマホ・PC 両対応です。

## 守っているルール（4条件）

1. **本文が取れなければ掲載しない**: 記事本文を抽出して400文字未満ならスキップ。
   タイトルだけから推測して要約することはしません。捏造記事は作りません。
2. **Gemini は無料枠のみ**: APIキーは環境変数（GitHub Secrets）経由でのみ渡します。
   クォータ超過などのエラー時は失敗として扱い、勝手に課金される仕組みはありません。
3. **公開サイト前提**: 掲載するのは公開ニュースの要約と元記事リンクのみ。
   社内情報・個人情報は扱いません。APIキーはコードに含めません。
4. **失敗時は前回の内容を保持**: 更新に失敗しても過去の記事は消えません。
   `data/news.json` に最終成功日時・最終試行日時・エラー内容を記録し、
   サイト上部に最終更新日時とエラーバナーを表示します。

## ユーザー側で必要なセットアップ（1回だけ）

1. GitHub で新規リポジトリを作成し、このフォルダの中身をアップロードする。
2. リポジトリの Settings → Pages で GitHub Pages を有効化する。
3. リポジトリの Settings → Secrets and variables → Actions に
   `GEMINI_API_KEY`（Google AI Studio で無料発行したキー）を登録する。
4. Actions タブで `daily-news` ワークフローを手動実行（workflow_dispatch）して初回動作を確認する。

以降は毎朝8時に自動更新されます。記事の修正・削除は `data/news.json` を編集して反映します。
